BM3D achieved the best average results. It outperformed NLM by approximately 1.62 dB in mean PSNR and achieved a higher mean SSIM. NLM was faster, with a median processing time of about 0.5 seconds per crop compared with about 17 seconds for BM3D.

Given these results, I would choose BM3D as the primary classical baseline. NLM is useful for showing the trade-off between image quality and processing time. Timings depend on the machine and exclude image loading, metric calculation, and saving to Drive.

The displayed example is the first validation crop listed in the manifest. In this example, BM3D preserves more fine texture, while NLM applies stronger smoothing. The scores shown on the image apply only to that crop. The table summarizes results across all 120 crops.
Keeping the comparison fair
Both methods processed the same noisy images. The clean reference images were used afterward to calculate PSNR and SSIM.

The dataset was split by scene so that all crops from a given scene stayed together. The fixed split contains 364 training crops, 120 validation crops, and 156 test crops. The noisy-only training manifest contains no clean-target paths.

The 120 validation crops include the 24 crops used for the earlier parameter calibration. Therefore, this validation comparison is not an independent held-out test. The 156 test crops form a separate split, and their results should be reported separately.

The previous M2 BM3D result rounds to 38.148 dB, while this run rounds to 38.149 dB. The actual difference is only about 0.000018 dB. Rounding makes the difference look larger than it is. The filter settings were unchanged, so this is not evidence of an improvement from parameter tuning.
